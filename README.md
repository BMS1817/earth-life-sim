# Earth — симулятор одной жизни

Локальная браузерная игра о жизни человека и продолжении рода: случайное рождение по данным ООН,
решения с трейд-оффом, семья и отношения, карьера и деньги, увлечения, конфликты, политика,
конституция, мемориал и наследие поколений. Работает без бэкенда и не отправляет жизни на сервер.

## Языки и распространение

Полная игра бесплатна на русском и английском. Язык определяется браузером и переключается на стартовом
экране или в меню; выбор сохраняется локально. Наследие и поколения доступны без оплаты. Необязательный
донат $2 на itch.io — поддержка разработчика, он не открывает контент и не даёт преимуществ.

## Запуск

Требуется Node.js 24.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Production-проверка:

```bash
npm test
npm run build
npm run preview
```

## Установка и оффлайн-режим

1. Откройте production-сборку по HTTP(S), не через `file://`.
2. Дождитесь сообщения **«Оффлайн-режим готов»** — service worker загрузит около 52 МБ данных,
   все 236 стран, арт, локальные флаги и шрифт в фоне. Список файлов формируется автоматически перед сборкой.
3. При поддержке браузера нажмите **«Установить игру»** или используйте команду установки браузера.
4. После готовности кэша можно отключить сеть и перезагрузить страницу: новые жизни, сохранения,
   мемориал, политика и наследие работают оффлайн.

Первая установка требует сети. Сохранения находятся в localStorage текущего браузера (`earth:life:v10`),
не в service worker и не в облаке. Очистка данных браузера удалит жизнь и родовую историю.
Старые v5–v8 переносятся автоматически; v1–v4 по ранее принятому решению не переносятся.

## Проверки

```bash
npm test                       # Vitest + проверка схемы PWA
npm run build                  # список PWA-файлов, TypeScript, production
npm run simulate -- 1000       # базовые жизни
npm run simulate -- 1000 --politics
npm run simulate-generations -- 1000 3
npm run test:scene             # сцена сохраняется при задержке новых спрайтов
npm run test:politics-flag     # локальный флаг online и после оффлайн-перезагрузки
npm run audit:i18n             # поиск непереведённых строк
npm run test:i18n              # RU/EN production, 32 момента, 3 поколения и оффлайн
npm run test:pwa:cache         # полный кэш и оффлайн-перезагрузка
npm run audit:war -- --base "http://127.0.0.1:4173/" --out shots/war-layers
npm run perf:startup -- --base "http://127.0.0.1:4173/" --runs 3 --assert
npm run perf:runtime -- --base "http://127.0.0.1:4173/" --cycles 10 --assert
npm run perf:runtime -- --base "http://127.0.0.1:4173/" --cycles 10 --mobile --assert
npm run shots -- --base "http://127.0.0.1:4173/?seed=review" --out shots/review
```

Перед browser-проверками запустите `npm run preview -- --host 127.0.0.1 --port 4173`.
Снимки и сырые выгрузки игнорируются git.

Повторная сборка политических данных, шрифта и флагов (не нужна для обычной игры):

```bash
npm run politics-data
npm run fonts
npm run flags
```

Для `npm run fonts` требуется Python с пакетами `fontTools` и `brotli`; скрипт проверяет совпадение
начертаний TTF и WOFF2. Обычная `npm run build` использует уже созданный WOFF2 и автоматически обновляет
235 локальных SVG-флагов из пакета `flag-icons`.

## Данные и лицензии

Полный список источников, преобразований и лицензий: [`data/SOURCES.md`](data/SOURCES.md).

- Население и семья: UN WPP / UN DESA, CC BY 3.0 IGO.
- Доход: Maddison Project Database 2023, CC BY 4.0.
- Конфликты: UCDP 26.1, CC BY 4.0.
- Политические профили: V-Dem v16, CC BY-SA 4.0; производные JSON содержат атрибуцию и ту же лицензию.
- Constitute и International IDEA по лицензионным ограничениям не встраиваются.
- Имена: Faker, MIT; русские названия: Unicode CLDR.
- Шрифт Press Start 2P: SIL OFL 1.1, файл лицензии в `public/fonts/OFL.txt`.
- Арт создаётся проектом через Blender и CSS; визуальные референсы не входят в игру.

После 2025 года политические профили — явный сценарий последнего режима, не прогноз V-Dem.
Альтернативные ВВП и смертность — ограниченная игровая модель, а не доказанный причинный эффект
конституционных решений; исходные WPP/Maddison не перезаписываются и показываются рядом.

## Доступность

Возрастная маркировка **15+**. Переключатель «Смягчить тяжёлые темы» доступен до каждой новой жизни
и в настройках; по умолчанию выключен. Поддерживаются клавиатура, подписи canvas и
`prefers-reduced-motion`. Игра не заменяет медицинскую помощь. Каталог конфиденциальных линий
поддержки: https://findahelpline.com/ .

## Структура

- `src/core/` — детерминированная игровая логика без DOM.
- `src/content/` — события и числовые правила.
- `src/ui/` — экраны, строки и пиксельная сцена.
- `public/data/` — компактные наборы по странам, загружаемые по мере необходимости.
- `public/art/` — оригинальные спрайты и метаданные.
- `scripts/` — сборка данных, симуляторы, PWA и production-снимки.
- `docs/` — план, решения, ADR и результаты приёмки.
