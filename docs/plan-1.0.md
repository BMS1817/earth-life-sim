# План до версии 1.0

Отправная точка: v0.1 (2026-11-12) — играбельная жизнь от рождения до смерти: ядро по данным
ООН, 69 событий + 7 кризисов, история, пиксельная сцена, автосохранение, экран конца.
Правила неизменны: перед каждым крупным шагом — грилл; статистика — с тестом против
исходных данных; тексты — через модуль строк; источники и лицензии — в `data/SOURCES.md`.

## v0.2 — Живые люди (цель: жизнь ощущается как отношения, а не как одиночный путь)

1. Модель людей: родители, братья/сёстры, партнёр, дети, 1–2 друга. У каждого: имя,
   возраст, характер (2–3 черты), отношения с игроком (число), память о совместных событиях.
2. Генерация семьи при рождении по данным страны (состав семьи — по доступным источникам;
   где нет данных — честная игровая оценка с пометкой).
3. Смерть близких — по тем же таблицам WPP, их события в летопись.
4. События с людьми: ссоры, помощь, праздники, болезни, переезды; существующие события
   (свадьба, ребёнок, развод) связываются с реальными персонажами.
5. Узоры летописи: «третий переезд», «пережил всех братьев» — детектор замечает и подсвечивает.
6. Конфликты UCDP/PRIO: источник, лицензия, войны как события с последствиями.
7. Экран людей: список близких с отношениями и памятью (не перегружать основной экран).
Приёмка: 3 разные жизни дают различимые семейные истории; тесты на связи людей, смерти,
узоры; живой тест пользователя.

## v0.3 — Карьера, навыки, деньги (цель: выборы имеют долгосрочную цену)

1. Навыки из образования: профессии по вехам (школа → курсы → работа по профилю).
2. Работа: доход от профессии × страна (Maddison), смена работы, повышения, кризисы.
3. Деньги как ресурс: баланс, расходы на жизнь, крупные покупки (жильё уже есть — увязать).
4. Вложения: 2–3 инструмента (наличные, облигации, рискованные) с честными рисками.
5. Балансный прогон: кривая дохода по жизни vs Maddison; никаких экспоненциальных дыр.
Приёмка: разные профессии дают разные траектории денег и событий; прогон баланса в docs;
живой тест.

## v0.4 — Наследие (цель: жизнь продолжается в детях)

1. Экран наследия: после смерти — выбор ребёнка как нового персонажа (если есть дети).
2. Передача: часть характера/навыков, деньги, семейная история и летопись рода.
3. Дерево рода: компактный экран поколений.
4. Новые события: воспитание, влияние родителей, различия поколений.
Приёмка: 2–3 поколения подряд играются без сбоев; seed-наследование документировано;
живой тест.

## v1.0 — Полировка и выпуск

1. Полный UX-проход: мобильная вёрстка (PWA), тач-таргеты, долгое нажатие подсказок.
2. PWA: manifest, оффлайн-работа после первой загрузки, «установка» на телефон.
3. Доступность и тяжёлые темы: переключатель «смягчить» на старте, контакты помощи, 15+.
4. Наполнение: довести события до ~100, проверить повторы на длинных жизнях.
5. Производительность: загрузка < 2 с на мобильном (ленивая загрузка mort/арта), плавная сцена.
6. Финальный QA: все тесты, полный прогон 1000 жизней без ошибок, проверка сейвов/миграций.
7. Деплой на статический хостинг, инструкция в README.
Приёмка: играется начисто на ПК и телефоне, оффлайн; пользователь подтверждает выпуск.

## Ориентировочные вехи
Каждый слой = 3–6 крупных рабочих сессий с гриллом перед стартом. Порядок слоёв не менять:
люди → деньги → наследие связаны, идти вперёд без предыдущего слоя будет переделкой.
