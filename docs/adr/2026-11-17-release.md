# ADR: оффлайн-релиз и доступность v1.0

**Контекст:** v0.5 имеет 143 зелёных теста и production на 243,74 КБ JS, но не имеет manifest,
service worker и стартового переключателя тяжёлых тем. `Scene.load()` выполняет 118 последовательных
запросов на спрайты/метаданные. Первичные JSON небольшие, полный `dist` — около 47 МБ; 38 МБ — таблицы
смертности по странам. Повторяемость событий в базовом прогоне — 29,09 повторов на жизнь.
Удалённого git remote нет.

**Решение:**
- Добавить Web App Manifest, PNG-иконки 192/512 и service worker с версионированным кэшем всех
  файлов production. Навигация — network-first с offline fallback, статика и данные — cache-first.
  Обновления не удаляют старый кэш до успешной установки нового. Сейвы не переносятся в SW, остаются
  в localStorage v9.
- Заменить массовую загрузку арта на кэшированные `ensureSheet`/`prepare`: только обязательные для
  текущего состояния изображения, остальные — при смене возраста, профессии, войны и мемориале.
  Главный цикл не ждёт каждый кадр; после загрузки выполняется один повторный render. Placeholder
  не вызывает ошибок, а существующий pixel-scale/Nearest сохраняется.
- На старте новой жизни — выбор смягчения и предупреждение 15+. Переключатель доступен и позже,
  по умолчанию выключен. Find A Helpline предлагается как внешний каталог поддержки, без заявления
  медицинской помощи. Canvas и долгое нажатие риска получают доступные подписи/клавиатуру; учитывается
  `prefers-reduced-motion`.
- Кулдаун событий — 8 лет; девять дополнительных климатических событий с четырьмя решениями.
  Проверить частоту повторов и баланс против текущих показателей, не меняя статистическую смертность.
- `package.json` получает версию 1.0.0. GitHub Actions публикует `dist` на GitHub Pages только после
  push в основную ветку пользовательского репозитория и включения Pages. README содержит запуск,
  проверку, оффлайн-установку, данные/лицензии и ограничения. Фактический внешний деплой не выполняется
  без репозитория и явной пользовательской публикации.

**Альтернативы:**
- A) Кэшировать только текущую страну — меньше трафика, но полноценная новая жизнь оффлайн невозможна.
- B) Загружать весь арт сразу параллельно — проще, но сохраняет лишние запросы и трафик.
- C) Смягчение по умолчанию — безопаснее, но меняет текущий контракт контента; пользователь выбрал
  выключенный переключатель, доступный всегда.
- D) Только увеличить контент — не решает повторы через 5 лет; выбраны кулдаун и локальные события.

**Последствия:** полная установка скачивает около 47 МБ в фоне; пользователь должен видеть статус
кэширования, а не принимать её за зависание. Оффлайн проверяется после завершения установки и при
активном service worker. Первый запуск без сети не обещается. Публикация остаётся действием пользователя.

**Затронутые файлы:** `public/manifest.webmanifest`, `public/sw.js`, `public/sw-assets.json`,
`public/icons/`, `scripts/build-pwa.mjs`, `src/ui/scene.ts`, `src/main.ts`, `src/ui/strings.ts`,
`src/content/local-events.ts`, `src/core/turn.ts`, `index.html`, `package.json`, `.github/workflows/`,
`README.md`, `tests/`, `scripts/`, `docs/`.

## Реализация и приёмка

1. PWA manifest/icons/SW, генерация списка файлов, регистрация и статус установки.
2. Ленивый арт, стартовая доступность, 15+, клавиатура и reduced motion.
3. Локальные события и A/B повторов/баланса.
4. Тесты PWA/схемы, production-замеры, полный цикл сети→оффлайн→перезагрузка, desktop/mobile.
5. README/GitHub Pages, финальные тесты/1000 жизней/симуляции и живой тест пользователя.

Коммиты и публикация только по явной просьбе пользователя.
