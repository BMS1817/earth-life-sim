# ADR: пошаговый год и полноэкранный игровой UI

**Контекст:** главный экран имеет внутренние полосы прокрутки у героя и событий, а вторичные экраны
построены как длинные документы. Управление временем добавляет 16 тиков, скорости, паузу, пропуск
и автовыбор. Пользователь утвердил ручной цикл, полноэкранные рабочие области и нижнюю мобильную
навигацию. Подробные решения — `docs/decisions.md`, раздел от 2026-11-20.

**Решение:**
- Удалить игровое время из UI. Обычный год имеет не более одного решения, тихий год завершается
  кнопкой «Прожить год». На вехах до трёх событий проходят последовательно в одном возрасте.
- Год завершается только после последнего ожидающего решения либо кнопки тихого года. Текущий фокус
  применяется на весь год. Сейв v10 и игровые данные не меняются; старые незавершённые tick/доли
  при первом новом переходе не смешиваются с новым циклом.
- Основной экран остаётся трёхзонным на ПК, без прокрутки у героя и события. Pixel-art использует
  только целые масштабы. Вторичные экраны получают общий каркас с верхней навигацией и тематическими
  сетками. Длинные списки имеют локальную прокрутку, но не прокручивают всю страницу.
- На телефоне нижняя навигация фиксируется с учётом safe area. Активная область занимает оставшуюся
  высоту, вторичные экраны используют ту же навигацию и возврат.

**Альтернативы:**
- A) Одно событие на каждый год — проще, но пользователь явно выбрал несколько решений на вехах.
- B) Пагинация вместо локального скролла — увеличивает число действий без пользы для длинных списков.
- C) Только визуальная правка CSS без изменения потока — оставляет зависание тихих лет после удаления
  кнопки пропуска и не решает управление на телефоне.

**Последствия:** браузерные сценарии больше не используют кнопки времени. Нужны новые сторожа для
тихого года, нескольких событий вехи, отсутствия прокрутки и старого сейва. Числа баланса, контент,
артуальные исходники и монетизация не меняются.

**Затронутые файлы:** `src/main.ts`, `src/core/turn.ts`, `src/ui/*-view.ts`, `src/ui/strings*.ts`,
`index.html`, browser-скрипты и тесты. Публикация только после двуязычного PC/mobile QA.

## Приёмка

1. Unit-тесты годового перехода, вех и сейва.
2. Снимки всех экранов RU/EN на 1920×1080, 1440×1080, 1280×720 и мобильной матрице с тачем.
3. Полный жизненный цикл, 32 момента, 3 поколения, оффлайн, Pages и itch.io iframe.
4. 1000 жизней; новых ошибок консоли, внешних/горизонтальных переполнений и обрезанного текста нет.
