# ADR: пакетирование страновых данных для itch.io

**Контекст:** production ZIP содержит 1563 файла, а itch.io запускает HTML5-пакеты только до 1000.
Из них 944 — отдельные JSON смертности, семьи, конфликтов и политики для 236 стран. Загружать все 45 МБ
при старте нельзя: это замедлит холодный мобильный запуск. Игровые данные, сейвы и логика не должны меняться.

**Решение:** после Vite-сборки группировать страновые JSON по размеру: смертность по 1 стране,
семью по 4, конфликты и политику по 16. Сохранять 325 лениво загружаемых пакетов и общий
`data/bundles/index.json`. В production загружать
только пакет текущей страны; dev и unit-тесты продолжают использовать исходные файлы. Индивидуальные
JSON удаляются только из `dist`, остаются в `public` для разработки и тестов. Пакетирование выполняется
перед формированием `sw-assets.json`, поэтому оффлайн-кэш содержит тот же сокращённый набор.

**Альтернативы:**
- A) Один JSON на тип данных — четыре запроса, но около 45 МБ при первом старте. Отклонено.
- B) Удалить часть стран, флагов или арта — уменьшает полную игру. Отклонено.
- C) Только скачиваемый ZIP без запуска в браузере — не выполняет требование HTML5 на itch.io. Отклонено.

**Последствия:** около 945 файлов вместо 1563; смертность загружается в исходном объёме одной страны.
Единые группы по 16 и 4 страны дали 5,7 и 3,2 с на холодном мобильном старте соответственно,
поэтому были заменены разными размерами пакетов до повторного performance gate.
Сейв v10, детерминизм, содержимое данных и API ядра не меняются. Любой новый страновый тип обязан быть
включён в пакетирование или явно исключён с проверкой лимита. Production QA обязан проверить несколько
стран из разных пакетов, оффлайн и количество файлов ZIP.

**Затронутые файлы:** `scripts/build-pwa.mjs`, `src/main.ts`, `tests/pwa.test.ts`, production ZIP,
`docs/status.md`.

## Реализация и приёмка

1. Пакетирование в `build-pwa.mjs --dist`, индекс и ленивые загрузчики в `main.ts`.
2. Проверка исходных данных всех 236 стран и числа файлов меньше 1000.
3. `npm run build`, `npm test`, `test:i18n` на production, запуск нескольких стран и оффлайн.
4. Пересобрать ZIP, обновить itch.io и проверить запуск внешней HTML5-версии.
