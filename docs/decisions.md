# Решения по проекту (грилл 2026-10-26)

Образец: https://1in8b.life/ru/ — текстовый симулятор одной жизни по статистике ООН/ВОЗ/ВБ
(vanilla JS + canvas 2D, localStorage, свой бэкенд, Stripe). Мы делаем свою версию с упором
на глубину решений.

## Цель и рамки
- Хобби/учёба, бесплатно. Код пишет Claude, пользователь решает и тестирует.
- Браузер + телефон (PWA). Без бэкенда: сохранения в браузере, статический хостинг.
- Язык — русский; все строки в одном месте (готово к переводу).

## Стек
- TypeScript + Vite, без игрового движка. Тесты — Vitest.
- Сцена — canvas 2D, пиксели без сглаживания.

## Данные
- Все ~190 стран, рождение с 1950 г.
- Собранные данные `public/data/` коммитятся в git (игра запускается из репозитория без
  сборки); сырые `data/raw/` — нет.
- UN WPP 2024 (демография, таблицы смертности 1950–2100), UCDP/PRIO (конфликты с 1946),
  Maddison Project (доход в прошлом), ЮНЕСКО/ВБ по мере надобности. В подсказке — источник.
- Расчёт по современным границам; игрок видит имя эпохи («Казахская ССР, СССР») и флаг;
  распад государства — событие с последствиями (доход, переезд).
- Полная история: исторические государства + ручной каталог знаковых событий.
- События — шаблоны с параметрами страны из данных; ручные тексты по странам позже.

## Механика
- Ход = год, темп игрока, спокойные годы можно промотать. Жизнь ≈ 20–40 мин.
- Рождение: по умолчанию случайно по реальным рождениям за год; режим «выбрать» страну/год.
  Имя — своё или случайное из имён страны.
  (грилл 2026-10-27) Год по умолчанию — любой 1950–2026 с весом по мировым рождениям
  (случайный человек из всех родившихся с 1950); дальше страна по рождениям года, пол по SRB.
  Жизнь после 2026 идёт по среднему прогнозу ООН, после 2100 — по таблице 2100 года.
- Код жизни (seed) — в адресе страницы (`?seed=…`), ссылка повторяет ту же жизнь. Гарантия
  только в пределах одной версии данных и правил.
- Реальная база + честные множители: решения сдвигают шансы в доказанных пределах.
- Колесо на 4 сектора: ↑ Традиция, ↓ Перемены, ← Близкие, → Я. Сектор может пустовать.
  В конце жизни — «компас жизни» по двум осям.
- Подсказка: стрелки влияния на шкалах; долгое нажатие — точные цифры + источник.
  (грилл 2026-11-08) Вероятности в подсказке — формат «N из 100 таких, как вы» + сетка
  из 100 точек, не проценты.
- (грилл 2026-11-08) События — гибрид: обычные годы система подбирает 1 событие по
  уместности, в знаковые возрасты игрок выбирает событие из короткого списка.
- (грилл 2026-11-08) Летопись в v0.1 простая (запись событий жизни); замечание узоров — v0.2.
- (грилл 2026-11-08) Цель «100%» — весь план до v0.4; реализация и приёмка — послойно,
  начиная с доведения v0.1 до играбельного состояния.
- (грилл 2026-11-08) Гибрид событий: выбор из 2–3 событий на вехах (~6, 12, 16, 18 лет)
  и в крупных кризисах; остальные годы — 1 событие от системы.
- (грилл 2026-11-08) Контент v0.1: ~60 шаблонных событий (~10 на фазу жизни) + ~100
  ручных исторических событий 1950–2026.
- (грилл 2026-11-08) Исторические данные v0.1: Maddison (доходы) + эпохи/распады + ручной
  каталог; UCDP/PRIO (войны как отдельная система) — v0.2.
- (грилл 2026-11-08) Имена: ищем полный открытый набор по странам до ядра, с лицензией
  (data/SOURCES.md).
- (грилл 2026-11-08) Сцена v0.1: 3–4 возрастные стадии персонажа + idle-анимация,
  дом по доходу/эпохе, фон по климату, параллакс; ходьбы и прочих анимаций нет.
- (грилл 2026-11-08) Автосохранение незавершённой жизни в localStorage после каждого хода,
  «Продолжить» на старте.
- (грилл 2026-11-12) Шкалы персонажа v0.1: здоровье, деньги, образование, близкие.
  Деньги стартуют из Maddison по стране/году. Компас считается отдельно от шкал.
- (грилл 2026-11-12) Влияние на смертность: события/состояние дают множители к qx,
  суммарный множитель ограничен ×0.5–×2; каждый множитель с обоснованием в данных события.
  Тест: нейтральная жизнь по-прежнему сходится к e0.
- (грилл 2026-11-13, v0.1.1) Выбор всегда с трейд-оффом: у каждого выбора есть и минус
  по смыслу (нет бесплатных «правильных» кнопок); эффекты видны стрелками до клика.
- (грилл 2026-11-13, v0.1.1) У каждого события всегда 4 выбора, все 4 сектора заполнены.
  Отменяет правило «сектор может пустовать».
- (грилл 2026-11-13, v0.1.1) Кнопки цветные по секторам: Традиция — золото, Перемены —
  голубой, Близкие — розовый, Я — фиолетовый.
- (грилл 2026-11-13, v0.1.1) Арт-итерация: выразительные стадии, анимации реакции на исход
  (радость/понурость). Полный UI-редизайн — в v1.0 по референсам Pinterest (предложить
  пользователю варианты перед редизайном).
- (грилл 2026-11-12) История v0.1: полная история всех стран с 1950 (эпохи: независимости,
  распады, переименования). Мировые знаковые события — строкой в летопись без выбора;
  кризисы страны (распады и пр.) — сторилеты с последствиями. Распад: деньги↓ + выбор
  «остаться/уехать» с риском; меняются название страны и флаг.
- Тяжёлые темы как в оригинале: по статистике, без подробных сцен, контакты помощи,
  переключатель «смягчить», 15+. Самоубийство игроку как вариант выбора не предлагается.

## Графика
- Пиксель-арт из 3D: low-poly модели в Blender → ортокамера, малое разрешение, тоон-шейдинг,
  ограниченная палитра → спрайт-листы, рендер скриптом по вариантам.
- Вид сбоку, параллакс 3 плана: местность/климат; дом (меняется с доходом и эпохой);
  персонаж и люди.

## Blender
- Портативный Blender 4.5.14 LTS: `D:\Clode\Tools\Blender-4.5.14\blender.exe` (общая копия,
  скопирована из папки Spider Clode; версия закреплена). Аддон MCP — в профиле
  `%APPDATA%\Blender Foundation\Blender\4.5\scripts\addons`, обновлён до свежего протокола.
- Живой режим (MCP) — строить и смотреть модели; пакетный (`blender -b ... -P ...`) — рендер
  спрайтов одной командой.
- Источник моделей: Python-скрипты по умолчанию; доведённое руками сохраняется в
  `assets/blender/hand/` и скриптами больше не перезаписывается.
- Цвета кожи/волос/одежды — перекраска палитры в игре (palette swap), не отдельный рендер.

## Грилл v0.2 «Живые люди» (2026-11-13)
- Близкие — постоянные персонажи с возрастом, характером, отношениями и памятью. Просчитываются
  ключевые повороты их жизни (работа, переезд, болезнь, дети), а не каждый год каждого человека.
- Отношения заметно влияют на игру: доступность и шансы помощи, ссор, примирения и других событий;
  характер и память участвуют в исходах. Влияние должно быть объяснимым, без скрытых нечестных наказаний.
- Семья при рождении: открытая статистика там, где она есть; пробелы — осторожная игровая модель
  с явной пометкой оценки. Не выдавать оценки за точную демографию.
- Порядок: сначала v0.2a «Люди» с отдельной проверкой, затем v0.2b «Конфликты» (UCDP/PRIO),
  чтобы войны затрагивали уже существующих близких.
- Полноценный круг v0.2a: родители, братья/сёстры, партнёр, дети и до двух близких друзей.
  Расширенный род не добавляем в этот этап.
- Знакомства и предложения могут возникать случайно; брак и решение о ребёнке — только явный выбор
  игрока. Существующие шаблоны не должны создавать супруга или детей без такого выбора.
- Партнёр или друг может сам разорвать отношения после накопленных конфликтов и охлаждения, но с
  предварительным заметным кризисом и возможностью отреагировать. Внезапных уходов без причин нет.
- Экран человека: шкала отношений + словесное состояние + последние общие воспоминания; точное число
  по долгому нажатию, как и остальные подробные подсказки.
- Общая шкала «Близкие» становится вычисляемой сводкой отношений с живыми близкими, а не независимой
  второй системой. Выборы меняют конкретных людей, шкала отражает итог.
- Семейные события могут быть дополнительными сценами после обычного события года, а не только заменой
  события из общего потока. Нужен отдельный предел частоты, чтобы сохранить управляемый темп.
- В режиме «смягчить» смерть близких остаётся по WPP, но подаётся нейтрально, без тяжёлых подробностей
  и дополнительных жестоких сцен.
- Сейвы v0.1.1 не мигрируем: при переходе на v0.2 старая жизнь завершается и предлагается новая.
  Поддержка двух режимов и ретроспективная генерация семьи не нужны.
- Дополнительная семейная сцена — не чаще одной за три года (после сцены два года без новых
  дополнительных сцен). Крупные кризисы и смерти — отдельные уведомления, не две сцены в один год.
- Память не забывает: каждый значимый поступок сохраняет вес до конца жизни. Нужен способ восстанавливать
  отношения новыми поступками, не стирая старые воспоминания.
- Черты характера раскрываются постепенно в совместных сценах; на экране видны только известные черты.
- Близкие появляются как варианты существующих пиксельных персонажей: портрет на экране людей и участник
  рядом с героем в семейной сцене. Большой новый набор анимаций в v0.2a не делаем.
- Постоянная память не мешает восстановлению: повторяющаяся забота и помощь могут перевесить старые обиды;
  записи не стираются, одно действие не отменяет череду конфликтов.
- У героя может быть до трёх детей; каждый появляется только после отдельного явного выбора и становится
  постоянным персонажем.
- Младшие братья/сёстры могут рождаться после героя по модели семьи с учётом возраста матери и интервалов;
  это не выбор игрока.
- Постоянное партнёрство, регистрация брака и дети — раздельные решения. Дети возможны в устойчивой паре
  без формального брака.
- Возможны разнополые и однополые партнёрства. Распределение — явно помеченная игровая оценка, а не
  «точная» статистика ориентации. Регистрация союза доступна только там и тогда, где это было законно;
  нужен отдельный открытый источник по законам страны и года.
- После автоматических тестов, сборки и живого прогона разработчика v0.2a показывается пользователю;
  v0.2b не начинается до его проверки и замечаний.
- Семейные сцены различаются по роли, характеру, возрасту и воспоминаниям; повтор одной ссоры блокируется.
  Проверять повторы длинными прогонами, а не уменьшать частоту ниже согласованной.
- (2026-11-15) Пользователь подтвердил живую проверку v0.2a и разрешил начать v0.2b «Конфликты».

## Грилл v0.2b «Конфликты» (2026-11-15)
- Данные: UCDP Organized Violence within Country Borders 26.1 (1989–2025), для 1950–1988 —
  UCDP/PRIO ACD и Non-State; CC BY 4.0. API с токеном не требуется, используются открытые ZIP.
- Конфликт распавшегося государства — общая история современных республик; численный риск
  распределяется между ними по населению, без умножения общего числа смертей в каждой республике.
- Базовый риск героя и близких: мирные + неустановленные погибшие / население. Потери сторон
  конфликта добавляются только к явно рискованным боевым решениям.
- После 2025 — вероятностная модель по последним 10 годам страны с пометкой «не прогноз»;
  названия будущих конфликтов не выдумываются.
- Кризисные сцены — в начале конфликта, при заметной смене фазы и при завершении, не каждый год.
- Прямое участие в боевых действиях — только для взрослых (~18–55 при подходящем здоровье),
  с заметным предупреждением риска и без подробных сцен насилия. Детям и пожилым — гражданские решения.
- Решения меняют риск конкретных близких и оставляют воспоминания. Защита семьи повышает риск героя,
  побег в одиночку — наоборот. Мгновенных случайных смертей в самой сцене нет.
- Денежные, психологические и миграционные последствия — ограниченная игровая модель в существующих
  диапазонах кризисов с явной пометкой. Смертность — только по UCDP.
- Сейвы v0.2a сохраняются миграцией в v3 с военными полями по умолчанию; прошлое не пересчитывается.
- Эвакуация в v0.2b — перемещение внутри страны: статус переселенца, расходы и сниженный риск.
  Международная миграция отдельным поздним этапом.
- В режиме «смягчить» боевой выбор заменяется гражданским, всегда остаётся четыре выбора;
  смерть остаётся с нейтральным описанием.
- По выбору пользователя — новые пиксельные сцены войны, не только затемнение фона. Состав сцен
  согласуется отдельно; кровь и подробности насилия не добавляются.
- (2026-11-15) Пользователь разрешил после v0.2b перейти к v0.3 без отдельного живого теста;
  разработческие прогоны и браузерная проверка остаются обязательными.
- Военная сцена: солдаты и техника по выбору пользователя, без крови и подробных сцен насилия.
- Статус внутреннего переселенца действует до конца опасной фазы + один год восстановления.
- Риск войны показывается словами без процентов/дробного знаменателя; не округлять редкий риск до 1%.
- До 1989 — state-based и non-state данные с явным ограничением отсутствия One-Sided Violence;
  отсутствующие смерти не дорисовываем моделью.
- Военный арт: статичные композиции + простой idle солдат и техники, отдельная эвакуация;
  без боевых столкновений, стрельбы, взрывов и реалистичных ран.
- В смягчённом режиме солдаты, техника, дым и взрывы убираются; остаются герой, близкие,
  повреждённый дом и гражданская эвакуация.

## Грилл v0.3 «Карьера и деньги» (2026-11-15)
- Личные финансы — реальный баланс в международных долларах 2011 года; шкала денег 0–100
  сохраняется для сцены и сравнений.
- Шесть направлений: медицина, образование, техническая/инженерная работа, промышленность/ремесло,
  сельское хозяйство, услуги/бизнес.
- Maddison остаётся страновым/историческим ориентиром; профессиональные доходы — диапазоны
  поверх него с явной пометкой игровой модели, без полной статистики ILO.
- Работа идёт карьерными этапами: доход/расходы автоматически, решения — профиль, смена работы,
  повышение, кризис, пенсия. Ежегодного рабочего события нет.
- Долг разрешён не больше годового дохода с умеренной реальной ставкой; сверх этого кредит закрыт.
- Вложения: наличные, осторожные облигации, диверсифицированный рискованный портфель.
  Реальная доходность с просадками, без гарантированной экспоненты.
- Базовые расходы автоматические по стране, семье и жилью; крупные решения отдельно.
- Жильё: родители, аренда, собственность, ипотека влияют на ежегодные платежи и сцену;
  ипотека — ограниченный срок.
- На вехе 18 лет — четыре профессии из шести по seed и образованию; сложные профили требуют
  соответствующего обучения. Остальные направления доступны при смене работы.
- Доходность вложений — ограниченная игровая модель с реальными просадками, не обещание рынка.
- Сейв v3 → v4: баланс вычисляется из шкалы и Maddison, профессия — из возраста/образования,
  портфель — наличные. Прошлое не пересчитывается.
- Финансовый экран «Деньги»: работа, баланс, жильё, вложения; на основном — баланс и шкала.
- Налоги — простая эффективная ставка по стране и доходу с пометкой игровой модели.
- Арт профессий: варианты одежды по шести направлениям и спокойный idle типичного действия,
  без отдельных фонов рабочих мест.
- Пенсия зависит от стажа, профессии и страны как игровая модель; работа после 65 — выбор.

## Грилл исследования 1in8b (2026-11-16)
- Исследование через игру и публичные материалы записано в `docs/research.md`.
- Пользователь выбрал большой пакет до «Наследия»: фокус года, хобби, отложенные действия,
  образ жизни/траты, питомцы и локальный финальный мемориал. Точный объём и очередь уточняются.
- Пользователь выбрал реальное время как у 1in8b вместо чисто пошагового года: 48 секунд на 1×,
  пауза в любой момент и обязательная на решениях, 1/2/4/8/16×, пропуск до решения и авторежим.
- Добавляется пятая шкала «Счастье» 0–100 для фокуса, хобби, образа жизни и итоговой карты.
  Прямого влияния на смертность нет; здоровье и отношения остаются отдельными.
- Пакет выпускается проверяемыми частями: A — время/фокус/хобби; B — действия/образ
  жизни/питомцы; C — мемориал/биография; затем отдельный этап P — политика.
- Старые сейвы v4 по решению пользователя не переносятся: обновление явно сообщает об этом и
  предлагает новую жизнь. Миграция финансов/людей не требуется.
- Авторежим выбирает обычные решения после короткого обратного отсчёта с возможностью перехвата;
  первая работа, дети, конфликты и крупные финансы всегда остаются ручными.
- Смена фокуса действует пропорционально времени, проведённому с ним в текущем году, без бонуса
  за переключение в последний момент.
- Счастье ограничено 0–100 и постепенно возвращается к 60; изменения фокуса ограничены, A/B-прогон
  обязан проверить отсутствие обязательного лучшего фокуса.
- Одновременно до трёх хобби, уровни 0–10 с растущей ценой времени; события на 3/6/10, уроки и
  турниры. Уровни открывают контент, а не бесконечный рост шкал.
- Один крупный отложенный план в год: поиск работы, курсы, работа мечты и подобное. Многолетние
  проекты занимают ежегодный слот на каждом этапе. Мелкие повторяемые траты идут отдельно.
- Автотраты включаются явно и не срабатывают при долге; после них должен остаться запас на
  обязательные годовые расходы. Автоматических займов нет.
- До двух питомцев: собака, кошка или маленькое животное, расходы, возраст, продолжительность
  жизни, сцены и память; смерть без тяжёлых подробностей.
- Имущество — полный набор: вещи, жильё, курсы, страховка, питание, благотворительность, поездки,
  лётная школа, арендная недвижимость, местные выборы и бизнес. Для сложных веток нужны отдельные
  правила и проверки, не просто магазин бонусов.
- Локальный мемориал: биография, счастье по годам, комната с предметами, фотоальбом, избранные
  воспоминания и последняя сцена. До 32 отмеченных моментов за жизнь.
- Двухосевой компас сохраняется; по выборам и времени фокусов вычисляются уникальный цвет и короткое
  название узора жизни, не заменяющее компас.
- После смерти добавляется одна визуальная сцена «подаренный день» главной несбывшейся мечте;
  она не меняет прошлое и не продолжает игру.
- Скрытая вкладка останавливает время и сохраняет состояние; оффлайн-лет и наград нет.
- Seed продолжает детерминировать рождение, события и исходы по `seed:age:salt`. Выбор и время
  фокусов записываются отдельно; ссылка повторяет мир и варианты, а не действия игрока. Полного
  replay по таймеру нет; одинаковые действия дают одинаковый результат.
- Авторежим не меняет фокус, выбранный игроком.
- Одно активное дело и до трёх арендных объектов: капитал, ремонт, простой и неудачи; гарантированной
  экспоненты и пассивной империи нет.
- Политическая ветка по решению пользователя включает местный, региональный и национальный уровни,
  реальные формы правления и конституции, смену конституции во власти и влияние на страну.
  Сроки зависят от конституции; президент может менять форму правления и правила переизбрания.
- Политика выделяется в отдельный этап P после A/B/C и до «Наследия». Изменения страны идут как
  явная альтернативная история: исходный WPP/Maddison виден, отклонения — игровая модель с лагом.
  Конституция меняется через конструктор поправок: форма правления, сроки, лидер, ветви власти,
  референдум и узурпация с противодействием.
- Ручная база 236 стран/территорий готовится после A/B/C и до P, с изменениями с 1950 года.
  Территории с невосстановимой историей получают явно помеченную общую оценку, не выдуманные статьи.
- A/B/C и P по отдельности проходят тесты, сборку, 1000 жизней, desktop/mobile и production-сценарий,
  затем живой тест пользователя. «Наследие» v0.5 начинается только после приёмки P.
- Серверная публикация, монетизация, музыка и копирование чужих текстов/чисел не входят.
