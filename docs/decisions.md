# Решения по проекту (грилл 2026-10-26)

Образец: https://1in8b.life/ru/ — текстовый симулятор одной жизни по статистике ООН/ВОЗ/ВБ
(vanilla JS + canvas 2D, localStorage, свой бэкенд, Stripe). Мы делаем свою версию с упором
на глубину решений.

## Цель и рамки
- Хобби/учёба, бесплатно. Код пишет Claude, пользователь решает и тестирует.
- Браузер + телефон (PWA). Без бэкенда: сохранения в браузере, статический хостинг.
- Язык — русский; все строки в одном месте (готово к переводу).

## Стек
- TypeScript + Vite, без игрового движка. Тесты — Vitest.
- Сцена — canvas 2D, пиксели без сглаживания.

## Данные
- Все ~190 стран, рождение с 1950 г.
- Собранные данные `public/data/` коммитятся в git (игра запускается из репозитория без
  сборки); сырые `data/raw/` — нет.
- UN WPP 2024 (демография, таблицы смертности 1950–2100), UCDP/PRIO (конфликты с 1946),
  Maddison Project (доход в прошлом), ЮНЕСКО/ВБ по мере надобности. В подсказке — источник.
- Расчёт по современным границам; игрок видит имя эпохи («Казахская ССР, СССР») и флаг;
  распад государства — событие с последствиями (доход, переезд).
- Полная история: исторические государства + ручной каталог знаковых событий.
- События — шаблоны с параметрами страны из данных; ручные тексты по странам позже.

## Механика
- Ход = год, темп игрока, спокойные годы можно промотать. Жизнь ≈ 20–40 мин.
- Рождение: по умолчанию случайно по реальным рождениям за год; режим «выбрать» страну/год.
  Имя — своё или случайное из имён страны.
  (грилл 2026-10-27) Год по умолчанию — любой 1950–2026 с весом по мировым рождениям
  (случайный человек из всех родившихся с 1950); дальше страна по рождениям года, пол по SRB.
  Жизнь после 2026 идёт по среднему прогнозу ООН, после 2100 — по таблице 2100 года.
- Код жизни (seed) — в адресе страницы (`?seed=…`), ссылка повторяет ту же жизнь. Гарантия
  только в пределах одной версии данных и правил.
- Реальная база + честные множители: решения сдвигают шансы в доказанных пределах.
- Колесо на 4 сектора: ↑ Традиция, ↓ Перемены, ← Близкие, → Я. Сектор может пустовать.
  В конце жизни — «компас жизни» по двум осям.
- Подсказка: стрелки влияния на шкалах; долгое нажатие — точные цифры + источник.
- Тяжёлые темы как в оригинале: по статистике, без подробных сцен, контакты помощи,
  переключатель «смягчить», 15+. Самоубийство игроку как вариант выбора не предлагается.

## Графика
- Пиксель-арт из 3D: low-poly модели в Blender → ортокамера, малое разрешение, тоон-шейдинг,
  ограниченная палитра → спрайт-листы, рендер скриптом по вариантам.
- Вид сбоку, параллакс 3 плана: местность/климат; дом (меняется с доходом и эпохой);
  персонаж и люди.

## Blender
- Портативный Blender 4.5.14 LTS: `D:\Clode\Tools\Blender-4.5.14\blender.exe` (общая копия,
  скопирована из папки Spider Clode; версия закреплена). Аддон MCP — в профиле
  `%APPDATA%\Blender Foundation\Blender\4.5\scripts\addons`, обновлён до свежего протокола.
- Живой режим (MCP) — строить и смотреть модели; пакетный (`blender -b ... -P ...`) — рендер
  спрайтов одной командой.
- Источник моделей: Python-скрипты по умолчанию; доведённое руками сохраняется в
  `assets/blender/hand/` и скриптами больше не перезаписывается.
- Цвета кожи/волос/одежды — перекраска палитры в игре (palette swap), не отдельный рендер.

## Слои
- v0.1 ядро: все страны/годы, рождение→смерть, история, решения с последствиями, колесо,
  пиксельная сцена, экран конца жизни.
- v0.2 живые люди (родные, друзья, партнёр, дети с характерами и памятью).
- v0.3 карьера, навыки, деньги, вложения.
- v0.4 наследие: игра за ребёнка (часть характера, денег, семейной истории).

## Не в v0.1
Параллельные жизни «в ту же секунду», мемориалы/публикация жизней (нужен сервер), музыка,
другие языки, монетизация.
