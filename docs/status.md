- Данные (скрипты в `scripts/`, источники и лицензии в `data/SOURCES.md`):

  ручные CN/PK/PH, региональные fallback), `income.json` (Maddison 2023, CC BY 4.0,
  169 стран + `_world`, 1950–2022; после 2022 — уровень 2022).
- Ядро (`src/core/`): ГСЧ mulberry32; рождение (год→страна→пол→имя); смерть по qx
  (периодная/когортная, доля последнего года); состояние `LifeState` (4 шкалы, компас,
  модификаторы смертности с cap ×0.5–×2, летопись); сторилеты с условиями/весами/рисками;
  ход = год: вехи 6/12/16/18 и кризисы — выбор до 3 событий, иначе 1 по уместности;
  под-ГСЧ по `seed:age:salt` — детерминизм не зависит от сохранений.
- Контент: 69 событий по фазам жизни (`src/content/events/*.ts`, по файлу на фазу).
  Баланс по прогону 500 жизней: ~49 событий/жизнь, ~11 повторов; тихие годы (35%),
  перезарядка событий 5 лет, возрастной дрейф здоровья (50+: −0.5, 70+: −1.2/год),
  близкие дрейфуют к 50. Средний возраст смерти 71.3, шкалы без переполнения.
- UI (`src/main.ts`, строки `src/ui/strings.ts`): игровой цикл, шкалы-бары, колесо 4 секторов
  со стрелками эффектов, риски с подсказкой «N из 100» + сетка 100 точек (долгое нажатие —
  подробности), автопромотка тихих лет, автосохранение в localStorage каждый ход,
  «Продолжить» на старте, экран конца с летописью и компасом.
- История: русские названия всех 236 стран (CLDR) + флаги; эпохи с 1950 для всех стран
  с изменениями (`src/content/eras.ts`: СССР, Югославия, Чехословакия, разделения,
  переименования, колониальные независимости); каталог из 76 мировых событий 1950–2026
  в летопись (`src/content/history.ts`); распады как кризисные сторилеты с выбором
  «остаться/уехать» (`src/content/crises.ts`, 7 кризисов).
- Пиксельная сцена (`src/ui/scene.ts`): canvas 256×192, Nearest, 3 плана с параллаксом
  от указателя; персонаж 4 возрастные стадии + idle 4 кадра (дыхание), тон кожи — palette
  swap по seed; дом 3 уровня по деньгам; фон 3 климата по стране. Арт: Blender-пакет
  `scripts/blender/build_all.py` → `public/art/` (см. раздел Blender-to-pixel в CLAUDE.md).
- Экран конца жизни: итог (имя, возраст, год, страна/эпоха), визуальный компас двух осей
  с маркерами (нормировка по числу выборов, «равновесие» при |v|<0.15), итоговые шкалы,
  число выборов, летопись. **v0.1 собран полностью (2026-11-12).**
- Тесты: 43 зелёных (+ компас).
- Живой прогон в браузере: рождение→вехи→риск→смерть→новая жизнь, перезагрузка
