## Blender-to-pixel: что важно в этом проекте
- Модели — только скрипт `scripts/blender/build_all.py` (пакетно:
  `blender.exe -b --factory-startup -P scripts/blender/build_all.py`). Ручные — `assets/blender/hand/`.
- Конфиг `assets/sprites.json`, палитра `assets/palette.hex`, один `px_per_unit` = 32.
- Выход: `public/art/` (листы + JSON + превью ×8). Персонажи — профиль, idle 4 кадра;
  дома 3 уровня; фоны 3 климата × 3 слоя (FLAT, без света).
- ⚠ Цвета материалов в Blender — в ЛИНЕЙНОМ пространстве: `mat()` конвертирует hex sRGB→linear,
  иначе рендер осветляет и палитра сбивается.

- Стек: TypeScript + Vite + Vitest. Без игрового движка и без бэкенда.
- Пользователь не программирует: код, запуск и проверку делает Claude; отчитываться
  простым языком, что изменилось в игре.
- Данные — только из открытых источников с указанием источника и лицензии
  (`data/SOURCES.md`). Сырые выгрузки не коммитить (`data/raw/` в .gitignore).
- Любая статистическая логика — с тестом против исходных данных (например, e0 из WPP).
- Тексты интерфейса — только через модуль строк, не хардкодом в коде.

## Геометрия персонажей: что важно в этом проекте
- Перед созданием/правкой humanoid-спрайтов — глобальный скилл `pixel-character-geometry`
  (`D:\Clode\Global\skills\pixel-character-geometry\SKILL.md`). Источники — `docs/research.md`.
- Кадр героя 64×96, взрослый chibi 3–3,5 головы, 9 возрастных стадий с собственными пропорциями
  и осанкой. Три силуэта: компактный, средний, широкий; не растягивать один шаблон.
- Текущая проекция — 2D front/side: герой в строгом боковом профиле, дом фронтальный;
  near/far-конечности и стопы читаются перекрытием. Pivot стабилен, корпус в idle ≤1 px.
- Production-арт создаётся из новых Kimi-исходников `assets/kimi/` командой `npm run art:kimi`;
  сцена собирается из отдельных модулей `public/art/kimi/` и `manifest.json`, не из готовых сцен.
- Герой без капюшона и плаща, с синей туникой: 6 внешностей, оба пола, 6 независимых тонов кожи,
  3 климата и модульные профессии. Платок допустим. Дома: 3 климата × 3 достатка + руины каждого.
  Деревья — лето/осень/сухие ветви, округлые кластеры и светлые стволы.
- Flat shading, ограниченная палитра, чистый тёмный контур. Запрещены 3D, градиенты, сложное
  затенение, размытие и anti-aliasing. Alpha только 0/255, без микселей.
- Проверка: native 1×, ×4/×8, skeleton, silhouette, сезонный лист деревьев, сравнение до/после,
  численный отчёт кадров/палитры и GIF ≥3 циклов.
